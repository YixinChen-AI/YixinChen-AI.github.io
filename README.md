# YixinChen-AI.github.io

Personal academic homepage of **Yixin Chen (陈亦新)**, PhD candidate in Medical Imaging AI at Peking University.

Live: <https://yixinchen-ai.github.io>

## Structure

```
.
├── index.html        # English homepage (default)
├── index.zh.html     # Chinese homepage
├── assets/
│   ├── css/style.css # Jon-Barron-style single-page layout
│   └── img/          # avatar.png, portrait.jpg
├── .nojekyll         # disable GitHub Pages Jekyll processing
└── README.md
```

## Local preview

Open `index.html` directly in a browser — no build step required.

## Deploy

This repo is the GitHub Pages source. Any push to `main` is published within ~1 minute.
